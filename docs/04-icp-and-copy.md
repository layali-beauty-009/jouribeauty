# ICP & Copy Voice

## Primary ICP

| Attribute | Detail |
|-----------|--------|
| Geo | **Saudi Arabia** (Riyadh, Jeddah, Dammam, Khobar) — secondary Gulf |
| Age | 22–45 |
| Gender | Women-led; **include men** in eye/anti-aging ads |
| Income | Middle to upper-middle; shops online via social |
| Behavior | Buys from TikTok/Snap after UGC; fears scams → needs **authority + COD** |
| Skin context | AC all day, occasional sun, stress, lack of sleep, heavy phone screen time |

## Psychographics

- Wants to **look fresh for work, family, content**  
- Skeptical of "miracle" — trusts **ingredient names + reviews + Saudi delivery**  
- Will pay more if **bundle saves money** and brand looks **real**  
- Needs **confirmation call** reassurance for COD  

## Voice & tone

| Do | Don't |
|----|-------|
| Gulf/KSA-friendly Arabic (يمكن، وايد، عشان، مب) | MSA فصحى جافة فقط |
| Short sentences, conversational | Long academic paragraphs |
| "يساعد على مظهر / إحساس" | "يعالج / يشفي / ١٠٠٪" |
| Specific scenarios (مكيف، سهر، دوام) | Generic "بشرة جميلة" |
| Social proof as **experiences** | Fake doctor endorsements |

## Dialect cheat sheet (KSA/Gulf)

| Phrase | Use for |
|--------|---------|
| "مب كذي وجهج لازم يبان" | empathy |
| "المكيف يشفّي البشرة" | AC pain |
| "وايد ناس في الخليج يعانون من…" | social proof intro |
| "ادفعي لما يوصل — بدون بطاقة" | COD |
| "فريقنا يتصل ويأكد طلبج" | confirmation |
| "الأكثر اختياراً" | 2-pack badge |

## Headline formulas (LP + ads alignment)

1. **Problem question:** "بشرتج باهتة من المكيف والسهر؟"  
2. **Mechanism:** "كافيين ٥٪ + رولر يهدّي الانتفاخ"  
3. **Offer:** "عبوتين بـ ٢٧٩ ريال — وفّري اليوم"  
4. **Risk reversal:** "الدفع عند الاستلام + تأكيد قبل الشحن"
