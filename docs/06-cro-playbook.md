# CRO Playbook

## Conversion stack (every money page)

Apply in order — user scrolls down increasing **trust** and **urgency**:

1. **Announcement bar** — COD + best offer + delivery  
2. **Hero** — pain question + mechanism + no medical claim  
3. **Trust chips** — 4 icons (COD, delivery, quality, returns)  
4. **Offer selector** — 3 tiers, default **279**  
5. **Sticky CTA** (mobile) — price of selected tier + "أضيفي للسلة"  
6. **Problem agitation** — 4–6 pains with ✕  
7. **Solution mechanism** — how hero ingredient works (science-lite)  
8. **Ingredients grid** — proof + Gulf tie-in  
9. **Alternatives destroyed** — why drugstore/clinic-only fails (respectful)  
10. **Timeline / results** — week 1–4 *sensory* expectations, "قد تختلف"  
11. **Social proof** — 3–6 quotes, city names (الرياض، جدة…)  
12. **UGC video placeholders** — 9:16 slots for TikTok embeds later  
13. **FAQ** — COD, delivery, usage, safety  
14. **Final CTA** — repeat offer selector  
15. **Footer trust** — policies  

## Authority signals

| Element | Placement | Copy angle |
|---------|-----------|------------|
| Ingredient % | Hero + ingredients | "كافيين ٥٪" not vague "formula" |
| Lab-quality | Trust strip | تعبئة وتخزين آمن |
| Routine clarity | How to use | صباحاً/مساءً steps |
| Bundle math | Offer cards | show compare-at strikethrough |
| Confirmation | Checkout | "نتصل قبل الشحن" |
| Scarcity | Honest only | "دفعة محدودة هذا الأسبوع" if true; else "طلبات كثيرة — قد يتأخر ١–٢ يوم" |

## Emotional triggers (ICP)

| Trigger | Copy hook |
|---------|-----------|
| Shame → confidence | "ما تحتاجين فلتر قوي كل مرة" |
| Fear of scam | COD + confirmation + real brand |
| FOMO | bundle savings ending (soft) |
| Laziness | "٣ قطرات فقط" |
| Identity | "بشرة الخليج تحتاج روتين مختلف" |

## AOV levers

1. Default **2-pack** selected  
2. **3-pack** labeled best value per unit  
3. Cart cross-sells with **bundle hint** ("أكملي الروتين")  
4. **99 SAR upsell** post-phone (impulse, timer)  
5. Show **per-unit price** on 3-pack ("≈ 116 ريال/علبة")  

## Confirmation / delivery rate (COD)

- Clear **total on cart** before submit  
- WhatsApp optional note: "سنرسل تأكيد واتساب" (if business uses WA)  
- Thank you page: **what happens next** (call within X hours, delivery 2–5 days)  
- Reduce fake orders: valid KSA phone + name min 2 words  

## Social proof rules

- No "cured acne" — use "لاحظت فرق في اللمعان"  
- Include **first name + city** only  
- 5-star visual OK; don't claim "10,000 sold" without data  

## Scarcity (ethical)

| OK | Not OK |
|----|--------|
| "الأكثر اختياراً — ينفد غالباً" | Fake countdown always at 00:01 |
| "٢٧٩ بدل ٣٩٨ — وفّري اليوم" | Hidden fees at checkout |

## Mobile CRO

- Thumb-zone CTA bottom fixed on LP  
- Offer cards full-width, tap-friendly  
- Checkout modal = single column, large inputs  
- Cart drawer 90vh max, cross-sell horizontal scroll  

## Ad → page continuity

URL params: `?utm_source=tiktok` — preserve for order row.  
LP hero **must match** ad hook (same pain line in first 200px).
